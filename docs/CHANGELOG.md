# 문서 갱신 이력

`docs/UIUX-설계문서.md`의 갱신 이력이다. 본문에서 분리해 여기로 옮겼다 —
후속 작업자가 찾는 것은 "왜 이렇게 됐는지"(설계 문서 4장)이지 "언제 바뀌었는지"가
아니므로, 날짜별 기록이 본문 분량을 차지할 이유가 없다.

설계 문서 부록 A에는 최근 5건만 남기고 전체는 이 파일을 가리킨다.
코드 변경 단위의 이력은 `git log`가 따로 들고 있다 — 여기는 **문서의 어느 절이
왜 바뀌었는지**를 남긴다.
